Single capture — one web address, one screenshot

Paste any web address and get a picture of that page, the whole page from top to bottom — not just the part that fits on a screen. It waits for the page to finish loading, scrolls through it so lazy images appear, closes the cookie banner and stops animations, then takes the shot.

Use it when you want to look at one specific page — checking a site before putting it in a list, or grabbing a single screenshot to send someone.

You get one image you can view here and download as a PNG. No company research, no spreadsheet — that is the Batch tab.

Batch — a whole list of companies, done for you

Give it a list of companies and it handles all of them start to finish. You do not have to know which pages to capture: a FlowHunt agent works that out for each company, then pagesnap screenshots every page it found.

  1. Upload a list of companies — a CSV or an Excel file, one company per line.
  2. For each company, the agent finds the homepage, About Us and product pages, and writes a short description of the business.
  3. Pagesnap captures every one of those pages, full length.
  4. You download a results.xlsx and a ZIP with one folder of screenshots per company.

Use it when you have more than a couple of companies and want the finished package rather than individual images.

Before you start pick a flow below. If this server already has a FlowHunt key configured you can leave the key and workspace blank; otherwise paste them in first.

Good to know the run lives on the server. You can close this tab, come back later, and it will still be going. Any single company can be re-run on its own without redoing the list.

Parallel runs is how many companies are captured at the same time — each one holds its own browser, so 3–4 suits a laptop and 10 (the maximum) needs a machine with the RAM to match. Every company gets its homepage, its about-us page and up to six product pages; where it has more, the row's warnings say how many were found.

Batch capacity

How many companies one run takes today, and what that ceiling is actually for.

50

companies per run, right now. A deliberate, temporary ceiling — not the final shape of the tool.

Why it's there

  • A safety margin from early load testing — a full run at 50 companies goes through cleanly every time.
  • Enforced twice — a message the moment the list loads, and a server check that can't be bypassed.
  • Easy to raise through configuration once a higher volume is verified safe.

What it costs

  • A list of 100+ companies has to be split into multiple 50-company runs by hand.
  • 50 is a cautious number from load testing, not a precisely measured ceiling.

The two modes

Single capture
One web address in, one full-page screenshot out. Nothing is researched and nothing is saved to a spreadsheet. Use it to check a page, or when you just want one image.
Batch (FlowHunt)
A whole list of companies. The agent decides which pages matter for each one, pagesnap captures them all, and you get results.xlsx plus a ZIP of screenshots sorted into a folder per company.

Reading a result

The status column
This is the agent's own verdict on its research — VerifiedUnverifiedFailed — decided before any screenshot is taken. It is not a report on whether the pages were captured.
So the two can disagree
A row can say Verified and have no screenshots (the site blocked the browser), or say Failed and have a complete set. Always check the screenshot columns for what was actually captured.
Warnings
Say what was odd but survivable — only the homepage was found, more than six product pages existed, or the agent used a different domain than the one you gave it.
Errors
Say why a page is missing in plain words: HTTP 403 means the site blocks automated browsers, and there is no way around it from here. Others are timeouts, invalid certificates, refused connections, and 404s.
failed to capture
In a screenshot column, means that one page could not be taken. The other columns for that company may still be fine.

Where your run is kept

Only one at a time
The server keeps one run on disk. Loading a different list replaces it — screenshots, spreadsheet and all. This is deliberate: keeping every run filled the disk and broke captures halfway through.
Download before the next list
If a finished run has not been downloaded, pagesnap says so and refuses to start a different list until you either download it or confirm you do not want it. Once downloaded, the warning goes away.
Re-running one company
The Run button on a single row redoes just that company and replaces its folder. Everything else is left alone, so a couple of failures never mean redoing the list.
Run unfinished
Picks up the rows that never completed. Run all redoes every row from scratch, including the ones that worked.

When something looks wrong

A blank or short screenshot
Usually a cookie wall or a page that needs scrolling before it renders. Try the same URL in Single capture to see it on its own.
Every page 403
That site refuses automated browsers. Nothing in the settings will change it — it has to be captured by hand.
No homepage found
The agent could not resolve the company to a site. Adding the website address to that row usually fixes it.
The run seems stuck
Lower Parallel runs. Each company holds its own browser, so 10 at once needs a machine with the memory for it.
