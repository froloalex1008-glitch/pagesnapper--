pagesnap

Full-page screenshots of JavaScript-rendered sites. Waits for hydration, forces lazy images, freezes animation, then captures.

Try:

Captured screenshots

Give it a FlowHunt flow and a CSV of companies (one per line — name and/or website, extra columns are fine). The CSV is loaded into the table below; run the whole list or any single row. For each company the flow finds the homepage, about-us and product pages, each is captured full-page as JPEG into a folder named after the company, and the ZIP contains those folders plus a results.xlsx index.

Parallel runs is how many companies are captured at the same time — each one holds its own browser, so 3–4 suits a laptop and 10 (the maximum) needs a machine with the RAM to match. Every company gets its homepage, its about-us page and up to six product pages; where it has more, the row's warnings say how many were found.

⬇ Download ZIP

Builds results.xlsx and one ZIP from whatever has finished so far. Re-run a row and press it again to rebuild — the ZIP has a fixed name and is overwritten each time, so the disk never grows past one run.
